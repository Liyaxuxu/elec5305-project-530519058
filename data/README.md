# Data

Use the University of Edinburgh [VoiceBank-DEMAND dataset](https://datashare.ed.ac.uk/handle/10283/2791) (doi:10.7488/ds/2117). Keep downloaded audio outside Git history.

Suggested layout:

```text
data/raw/clean_trainset_28spk_wav/
data/raw/noisy_trainset_28spk_wav/
data/raw/clean_testset_wav/
data/raw/noisy_testset_wav/
```

Record the release, checksum, speaker split, noise split, and every generated mixture seed before running final experiments.
